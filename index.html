Tentang Saya

Saya adalah Admin Project dengan pengalaman dalam administrasi proyek, pengendalian data, document control, dan monitoring progres proyek housing serta infrastruktur secara multi-proyek. Saat ini saya juga menempuh pendidikan D4 Kearsipan di Universitas Terbuka.

Dalam pekerjaan, saya terbiasa memonitor progres sekitar 15–20 proyek serta mendukung pengendalian data dan pelaporan untuk 3 Project Manager. Saya menyusun laporan harian, mingguan, dan bulanan sebagai dasar evaluasi serta pengambilan keputusan manajemen.

Selain memiliki kemampuan di bidang administrasi, saya juga mengembangkan sistem web dan otomatisasi sederhana untuk membantu proses input data, reporting, pengelolaan dokumen, penyimpanan file, dan rekapitulasi data agar pekerjaan lebih cepat, terstruktur, dan minim kesalahan manual.

  • Monitoring dan pengendalian progres proyek housing serta infrastruktur
  • Project administration, document control, filing, dan pengelolaan MoM
  • Validasi dan sinkronisasi data antara sistem dengan kondisi lapangan
  • Pengolahan data menggunakan Microsoft Excel dan Google Sheets
  • Otomatisasi reporting menggunakan Google Apps Script
  • Pengembangan sistem berbasis HTML, CSS, JavaScript, dan Bootstrap
  • Analisis kendala proyek menggunakan pendekatan 4M
  • Koordinasi dengan Project Manager, tim lapangan, purchasing, dan vendor

Saya tertarik mengembangkan karier di bidang administrasi, document control, data reporting, dan system automation dengan memanfaatkan teknologi untuk meningkatkan efisiensi serta akurasi proses kerja.

Keahlian

Kombinasi kemampuan administrasi proyek, pengelolaan dokumen, pengolahan data, serta pengembangan sistem untuk mendukung efisiensi dan akurasi pekerjaan operasional.

Project Administration

Monitoring progres proyek, penyusunan laporan harian, mingguan, dan bulanan, pengelolaan action plan, serta dukungan administrasi untuk Project Manager.

Document Control

Pengelolaan dokumen proyek, filing, Minutes of Meeting, dokumentasi lapangan, laporan kendala, evaluasi vendor, dan tracking tindak lanjut.

Data & Reporting

Pengolahan dan validasi data menggunakan Microsoft Excel dan Google Sheets, termasuk VLOOKUP, HLOOKUP, Pivot Table, dashboard, dan visualisasi data.

System Automation

Pengembangan sistem web dan otomatisasi menggunakan HTML, CSS, JavaScript, Bootstrap, Google Apps Script, Google Sheets, dan Google Drive.

Problem Analysis

Analisis kendala proyek menggunakan pendekatan 4M, identifikasi akar masalah, monitoring penyelesaian, serta penyusunan tindak lanjut.

Coordination

Koordinasi lintas fungsi dengan Project Manager, tim lapangan, purchasing, vendor, supplier, dan departemen terkait.

System Management

Pengelolaan data melalui ERP-like system, Project Management System, sinkronisasi data, serta pengecekan kesesuaian data lapangan.

Professional Skills

Communication, time management, attention to detail, problem solving, kerja sama tim, dan kemampuan beradaptasi dengan proses kerja baru.
