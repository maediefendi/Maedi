Tentang Saya

Saya adalah profesional administrasi dan logistik dengan pengalaman dalam project administration, project control, reporting, document control, validasi data, serta proses administrasi pengadaan material. Saat ini saya sedang menempuh pendidikan D4 Kearsipan di Universitas Terbuka.

Dalam pekerjaan, saya terbiasa mendukung kebutuhan operasional proyek melalui pengelolaan data, penyusunan laporan progres, monitoring action plan, pengelolaan dokumen proyek, serta koordinasi dengan Project Manager, tim lapangan, purchasing, supplier, dan vendor.

Pada bidang logistik, saya terbiasa melakukan pengecekan ketersediaan material, mengelola dokumen Purchase Order (PO), Delivery Order (DO), Goods Receipt (GR), EAF, dan LPJ, serta memastikan data administrasi tetap akurat, terdokumentasi, dan mudah ditelusuri.

  • Administrasi proyek, monitoring progres, MoM, action plan, dan document control
  • Administrasi logistik: PO, DO, GR, EAF, LPJ, supplier dan vendor coordination
  • Validasi, sinkronisasi, dan pengolahan data operasional
  • Pengolahan data menggunakan Microsoft Excel dan Google Sheets
  • Pembuatan dashboard dan visualisasi data sebagai bahan evaluasi
  • Pengembangan sistem sederhana berbasis HTML, CSS, JavaScript, Bootstrap, dan Google Apps Script
  • Integrasi Google Sheets dan Google Drive untuk otomasi administrasi
  • Problem solving, analisis 4M, koordinasi lintas fungsi, dan attention to detail

Fokus karier saya berada pada bidang administrasi, logistik, document control, data reporting, dan system automation untuk mendukung proses kerja yang lebih rapi, cepat, akurat, dan terukur.

Keahlian

Kombinasi kemampuan administrasi proyek, administrasi logistik, pengelolaan dokumen, pengolahan data, serta pengembangan sistem untuk mendukung efisiensi dan akurasi pekerjaan operasional.

Project Administration

Monitoring progres proyek, penyusunan laporan harian, mingguan, dan bulanan, pengelolaan action plan, serta dukungan administrasi untuk Project Manager.

Logistics Administration

Pengelolaan administrasi material, PO, DO, GR, EAF, LPJ, pengecekan ketersediaan material, serta koordinasi supplier dan vendor.

Document Control

Data & Reporting

System Automation

Problem Analysis

Coordination

Koordinasi lintas fungsi dengan Project Manager, tim lapangan, purchasing, vendor, supplier, dan departemen terkait.
