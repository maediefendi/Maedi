Logistics Administration, Project Administration & Data System

Saya adalah profesional administrasi dan logistik dengan pengalaman dalam project administration, project control, reporting, document control, validasi data, serta proses administrasi pengadaan material.

Dalam pekerjaan, saya terbiasa mendukung kebutuhan operasional proyek melalui pengelolaan data, penyusunan laporan progres, monitoring action plan, pengelolaan dokumen proyek, serta koordinasi dengan Project Manager, tim lapangan, purchasing, supplier, dan vendor.

Pada bidang logistik, saya terbiasa melakukan pengecekan ketersediaan material, mengelola dokumen Purchase Order, Delivery Order, Goods Receipt, EAF, dan LPJ, serta memastikan data administrasi tetap akurat dan mudah ditelusuri.
